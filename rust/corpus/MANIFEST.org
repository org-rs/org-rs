#+title: Corpus Manifest and Licensing

* Purpose

This directory contains real-world Org documents used solely as a /testing
corpus/: the org-rs parser is run over them and its output compared against the
Emacs =org-element= oracle to detect discrepancies. The files are parser-input
fixtures only — never modified, executed, or redistributed as functional works.

* Licensing basis

Every file below is recorded with its author/source, its license, and the
evidence for that license. Three kinds of basis appear:

- *declared / verified* — the file (or the upstream repository/site it comes
  from) declares an explicit license. All such licenses here are GPL-compatible:
  GNU FDL 1.3+, GPL v3(+), MIT, Apache-2.0, or CC BY-SA 4.0 (one-way compatible
  with GPLv3 per Creative Commons and the FSF).
- *upstream policy* — the file is published under a project-wide license (the GNU
  Org manual under the GNU FDL; Worg content under GNU FDL / GPL) even though the
  individual file carries no inline header.
- *author permission (undeclared license)* — the upstream carries no discoverable
  license. The author's explicit permission was obtained to include the document
  as a testing corpus. It remains the copyright of its author and is used here
  for parser testing only.

If you are an author listed here and want your document removed, open an issue
and it will be dropped from the corpus.
